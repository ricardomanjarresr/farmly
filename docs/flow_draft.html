A Red Note–style discovery feed for fresh produce

This is a walkthrough of how the product would work end to end, built from what the team has confirmed so far. Nothing is coded yet — review this together and tell me what to change before we split into branches.

The loop

End-to-end flow

Six steps, entirely automatic once a farmer posts. No login for buyers, no negotiation, no B2B — browse, tap, buy.

1
Farmer posts on Telegram

Photo + voice/text: name, price, qty, expiration

2
AI builds the listing

Structured post: product, price, farm, photo

3
Post joins the feed

Appears instantly on the web discovery feed

4
Buyer discovers

Scrolls, searches, likes, saves — no account

5
Buyer taps Buy

Picks qty, gives name + phone, confirms — on the web

6
Farmer sees the order

Checks /pedidos in Telegram, fulfills it

What makes it “discovery”

  • Grid feed, newest first. No algorithm to build for the demo — the visual density and freshness do the work.
  • Like & save on every card, no account needed to browse.
  • Search + category chips for produce type and distance.
  • Comments and following a farm are in scope, but first to cut if time runs short.
  • Everything a buyer sees comes from a farmer’s Telegram post — nobody manually enters this.

What happens on confirm

  • No payment charged — this is a reservation commitment, simulated for the demo.
  • Order is written to the shared database, tied to that listing.
  • Buyer never leaves the web page — no redirect to Telegram.
  • Farmer is notified inside Telegram, sees it via /pedidos.

Why keep it here

  • Farmer never installs an app or learns a new interface — same as before.
  • One data-entry path in, which keeps the build simpler.
  • /mislistings and /pedidos replace any need for a farmer login or dashboard.
